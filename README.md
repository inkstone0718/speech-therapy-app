# 華語構音線上測試系統

## 專案簡介
為語言治療師設計的華語構音練習工具，可依據目標聲母和音節位置搜尋詞彙。

## 功能特色
- 🎯 依聲母（ㄅㄆㄇㄈ...）篩選詞彙
- 📝 支援雙音節、三音節詞彙
- 📍 可指定目標音在詞中的位置
- 🖼️ 每個詞彙配有圖片輔助
- 💡 點擊卡片查看詳細資訊

## 部署方式

### 本地開發
```bash
python3 -m http.server 8080
# 開啟 http://localhost:8080
```

### 免費線上部署

#### 1. GitHub Pages（推薦）
1. 上傳程式碼到 GitHub
2. Settings → Pages → Source 選擇 main branch
3. 自動部署到 `https://username.github.io/repository-name`

#### 2. Netlify
1. 拖拽專案資料夾到 [netlify.com](https://netlify.com)
2. 自動獲得免費網域

#### 3. Vercel
1. 連接 GitHub 帳號
2. 匯入專案即可部署
